KITE CONNECT
1. Go to developers.kite.trade → create an app → get your API Key
2. Open https://kite.zerodha.com/connect/login?api_key=YOUR_KEY&v=3 in browser
3. Login → copy the request_token from the redirect URL
4. Generate an access_token via your backend (or use Kite's developer console)
5. Paste both below — your holdings sync automatically to the screener
